# Prompt 5: Clarification Questions

## Purpose  
To generate a set of clarification questions aimed at resolving ambiguities or gaps in the information provided. This step focuses exclusively on formulating questions to better understand the context or requirements, without making any assumptions or providing answers.

## Inputs  
- The initial user query or request.  
- Any relevant context or background information gathered from previous steps.  
- Identified ambiguities, uncertainties, or incomplete details that need further clarification.

## Process  
- Analyze the input to detect unclear or missing information.  
- Formulate concise, targeted questions that seek to clarify these points.  
- Ensure questions are neutral and do not imply assumptions or suggested answers.  
- Limit the output strictly to questions; do not attempt to answer or interpret the information.

## Outputs  
- A list of clear and relevant clarification questions intended to elicit additional information from the user or stakeholders.

## Notes  
- This step is critical for refining understanding before proceeding to solution generation or decision-making.  
- Avoid combining questions with statements or hypotheses.  
- Questions should be specific enough to guide the next interaction effectively.
