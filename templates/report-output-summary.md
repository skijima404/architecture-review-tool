## Findings

### Finding ID: F-012  
**Title:** Retry logic missing in API layer  
**SC Impacted:** SC-002 (Reliable Service Recovery)  
**Priority:** High  
**Phase to Address:** D (System Design)

**Explanation:**  
This issue compromises system reliability. Without proper retry handling, temporary failures may escalate to user-visible outages. The affected API is part of the payment workflow, increasing business risk.

**Recommended Action:**  
Introduce retry mechanisms with exponential backoff and circuit breakers for all outbound API calls. Ensure test coverage for failure simulation.

**Optional Reflection:**  
If this API fails in production, who detects it first? Is the recovery automatic or manual?
